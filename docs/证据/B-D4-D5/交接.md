## 从仓库根目录复现

```powershell
$scripts = 'platform/scut-schedule/skills/scut-schedule/scripts'
$evidence = 'docs/证据/B-D4-D5'
$output = 'work/d4-d5-b-repro'
python -B -X utf8 "$scripts/schedule.py" prepare --bundle "$evidence/overnight-bundle.json" --out-dir "$output"
python -B -X utf8 "$scripts/runtime.py" snapshot --existing "$output/schedule.csv" --mode example --today 2026-11-30 --out "$output/snapshot.json"
python -B -X utf8 "$scripts/presentation_runtime.py" conflicts --existing "$output/schedule.csv" --mode example --today 2026-11-30 --format json --out "$output/conflicts.json"
python -B -X utf8 -m unittest discover -s tests -k cross_day_overlap -v
```

A 的调用入口为随包 `runtime.py timetable/message/location/update/snapshot`。结构化跨日事项用 `schedule.py prepare` 生成写入计划，冲突用 `presentation_runtime.py conflicts` 读取 CSV 并计算。实际云端写入由当前账号的 WorkBuddy 原生入口执行。

本轮实测范围是本地写入计划、CSV 回读和随包冲突呈现。0.5.0 已另用一组跨日样例完成[原生平台验收](../../平台验收-0.5.0.md)。本交接中的最小输入在线未复测，第二账号按任务要求记为未测。
