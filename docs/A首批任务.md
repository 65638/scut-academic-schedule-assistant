## 交付结果

在 WorkBuddy 上接通：打开作品 → 载入示例 → 保存一条事项 → 查询本周安排 → 重新进入后仍可查到。用第二个独立账号验证作品可访问、示例可运行、个人事项互不可见。

你的首批职责是平台与集成。B、C、D 的模块尚未由本任务安排，先使用最小样例接通数据流，并明确哪些接口仍使用样例。

## 执行顺序

1. 阅读仓库 README、AGENTS.md 和启动方案，检查本机可访问的 WorkBuddy 入口与已有项目。记录实际可用的作品分享、知识库、Skill、状态存储能力。
2. 选择平台支持的最直接实现，建立入口和示例载入。平台确定前不要搭独立 Web 应用或预建后端。
3. 用以下样例接通保存、查询和重新进入后的恢复；再次载入相同示例时保留一份记录。
4. 观察第二账号的实际行为。无法操作第二账号时，完成其余工作，给出主管可执行的最短验证步骤，并明确此项未验收。
5. 保存可复用配置、必要脚本和使用说明；在开发分支提交首批结果，提供变更摘要、运行结果、作品链接（若已生成）及具体阻塞。
