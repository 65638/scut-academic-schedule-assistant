# 申报文字底稿｜校园学业日程助手

2026-11-11整理，适用0.5.0，收尾基线eaaee46。由原D2–D3底稿更新而来；此文件是文字底稿，未按尚未取得的主办方模板填报，也未正式提交。不得将待执行演示或本地证据写成D平台实测。

## 作品名称与定位

名称：校园学业日程助手。面向华南理工大学大学城校区学生，专业不限；具体通知的年级、学院、培养层次和其他资格按原文判断。入口为WorkBuddy专家，当前已发布版本0.5.0。

## 核心问题（100字以内）

校园通知、课表、作业和群消息分散，期限与变更容易遗漏。助手将信息整理成有原文依据的个人日程，集中呈现本周安排、待确认和实际变化，并提示已知时段的冲突，给出不修改原截止的准备建议。

## 方案与实际能力

用户提供校园消息、通知或课表，助手识别事项与来源，将日期、时刻、地点、状态和待确认字段整理后按明确请求保存到本人个人表。保存前读取最新表，写入后回读核对，不能把本地文件写成云端成功。每个新任务从当前账号上下文发现个人空间和日程表，不在专家包固定作者标识。

消息可拆出多个事项；明确发送日用于相对日期换算。地点更正、调课、延期、取消与完成按业务编号定位，保留原来源和历史，重复原文不覆盖已有更正。通知展示适用对象、材料、办理入口及原文/更正依据。缺日期或时刻时留待确认，不把只有日期的作业补成23:59。

周计划按周一到周日呈现；今晚简报列明天课程活动、今天至后天截止、逾期、全部待确认与今天真实历史。本周简报保留周内事项。完成/取消不继续提醒或占用，普通周计划可回顾已完成事项。已知完整课程活动时段参与冲突计算，输出双方业务编号与重叠区间；提交截止不作为占用。按用户明确日期范围与每日窗口列空档，为预计用时给“建议”准备时段；不足时给可用量和缺口，不改教师DDL。

## 真实提醒方式与限制

提醒发生在用户查询时的WorkBuddy对话内，没有后台定时推送、外部通知服务或教务账号抓取。知识资料为随包快照，不保证实时更新；复杂未覆盖表达需对照原文确认。未知活动时长会使空档结论待核对，建议不构成实际预约。多会话并发写入没有平台业务编号唯一约束，不承诺并发去重。截图识别不作为已完成能力，U5不属于本轮收尾条件。

今晚冲突按明日的分段日期筛选，跨午夜另一日的区间应查周计划或完整冲突页，不能把局部简报写成全时段冲突报告。

## Skill、资料和贡献披露

实际组成见[Skill与知识库清单](Skill与知识库清单.md)。项目自有scut-schedule Skill与专家角色提示负责平台编排；WorkBuddy内置library负责个人表访问，expert-manager负责校验、注册与打包；M2提示词及来源台账随0.5.0资料引用。模型理解和组织自然语言，标准库脚本完成已覆盖规则与区间计算，模型推测不代替学校原文。

真实知识包括2027届求职补贴通知、2026–2027第一学期校历和大学城作息，保留发布者、URL、发布日期/未知及收录时间。合成联调通知、画像和课程单独标记example；合成课程14:00–15:40不能写成官方5–6节14:00–15:35。资料无独立版本号时使用仓库路径与Git提交定位，不虚构版本号。
