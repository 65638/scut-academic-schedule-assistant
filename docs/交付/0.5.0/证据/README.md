# 本批本地证据

由`modules/m3/verify_delivery.py`实际生成，全部为合成输入，在内存中经本地CSV保存恢复，不是云端快照、平台截图或独立账号实测。

- `合成输入.json`：本批完整输入，可与脚本和输出逐项对照。
- `周计划.md`、`今晚简报.md`、`本周简报.md`：完成/取消/待确认和三天范围组合。
- `完成后空档.md`：会议已完成，课程占用结束于15:40。
- `跨日冲突.md`：跨月跨午夜两段各30分钟。
- `通知与周外更正依据.md`：简单示例通知更正到11-27，原文及周外更正仍可追溯。
- `准备时长不足.md`：180分钟需求、120分钟窗口、60分钟缺口。
- `检查结果.json`：执行时间、实际检查结果及未测平台项。
- `源包文件校验.json`：当前36个源包文件的SHA256。

来源收录/更正时间在输入中是合成测试值；执行日期以检查结果的generated_at为准。报告中合成业务编号供匹配事项，不是个人表记录ID。本批未保存个人账号数据。
