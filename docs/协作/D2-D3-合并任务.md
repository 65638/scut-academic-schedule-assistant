4. 同一组事项的周计划、冲突、空档和简报；待确认内容与实际历史可恢复。
5. 通知更正的已有事项更新及新适用用户新增；更正重放无重复写入。
6. 独立账号收到随包资源并可运行，新任务能恢复，双方记录互不可见。
