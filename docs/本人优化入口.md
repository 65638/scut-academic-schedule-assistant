## 本地常用命令

在仓库根目录执行，Python 3.9+，业务脚本只用标准库：

```powershell
python -B -X utf8 -m modules.m3.demo --out-dir work/owner-demo
python -B -X utf8 -m modules.m3.presentation free --input work/owner-demo/input.json --start 2026-11-17 --end 2026-11-17 --day-start 14:00 --day-end 18:00
```

第一条会生成 `work/owner-demo/input.json`、`week.md`、`tonight.md` 等结果，第二条据此计算给定窗口的空档。

只做本地计算的通知示例：

```powershell
python -B -X utf8 platform/scut-schedule/skills/scut-schedule/scripts/notice_runtime.py notice `
  --input platform/scut-schedule/skills/scut-schedule/examples/m2-notice-save.json `
  --out work/owner-demo/notice-plan.json
```

这些命令只生成本地结果，不写个人表。修改通知逻辑后可选 `python -B -X utf8 -m unittest discover -s modules/m2/tests -v`；修改平台适配或呈现后按对应测试文件运行，入口见[专家说明](../platform/scut-schedule/README.md)和[M3 说明](../modules/m3/README.md)。纯文档无需重跑业务测试。

本轮按顺序实跑以上三条命令：演示生成 5 条日程、1 条待核对事项和 1 组冲突；给定窗口返回 16:00–18:00、120 分钟空档；通知计划为 1 新增、0 更新、`saved_to_cloud=false`。这只核对入口可运行，既有业务测试和平台证据继续复用。

`modules.m3.verify_delivery` 限定 0.5.0，只用于 D 原交付提交 `845b73e` 的历史复现，不是当前 0.5.1 的验证命令。
