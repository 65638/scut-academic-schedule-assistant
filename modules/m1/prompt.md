# WorkBuddy 消息处理提示词

将用户提供的原文、原发送日和模式传给 M1 的 `parse_message`。示例明确标注为 `example`。如有上游来源编号，传入 `source_id` 并在后续补充资料时沿用。保留原文、每个事项的原文片段和来源引用。

原发送日缺失时传 `null`。有 `questions` 时，向用户询问对应字段。日期未知的事项按 `pending_fields` 标注。仅给日期时保留空的时刻，活动结束时刻按原文填写。提交事项的 `start_time` 用「截止」呈现。

脚本报出暂不支持的句式时，说明需要用户把具体日期、时刻和事项写清楚。保存由 A 的平台流程处理，以保存操作的实际结果为准。
